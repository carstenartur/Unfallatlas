and 2.22.4 in QA. These resolve the reviewed dependency versions; version-based
advisories alone do not prove an exploitable path in this application.

**Release Workflow** (`.github/workflows/deploy-release.yml`) with:

| Input | Value |
|---|---|
| `next_development_version` | `2.1.5-SNAPSHOT` |

The workflow always checks out `main`; selecting a preparation branch in the

separately and are not part of its artifacts. Its actual Java setup is JDK 25
(the existing step label still says Java 21), and Maven installs the pinned Node
24.17.0/npm 11.21.1 toolchain.

```bash
PLAYWRIGHT_INSTALL_SYSTEM_DEPS=1 mvn -B -ntp clean verify \
  -Prelease-site,pages,e2e,system-it,location-brief-golden,document-render \
  '-Dfailsafe.includes=**/*IT.java'
```

Keep the full Failsafe include: the Golden profile otherwise narrows the test
selection. Preserve the existing timeouts, security, media, licence and provenance
