## Visuelle Prüfung

Die 17 Desktopansichten wurden als Gesamtübersicht sowie in Originalauflösung
auf Datenpunkte, Cluster, Heatmap, Legende, Filterzustände, Auswahlrechteck,
Kartenmodi und Exportdialog geprüft. Die drei 440×620-Panelansichten wurden
separat in Originalauflösung auf Lesbarkeit, border-box-konforme Breite,
Touch-Zielabstände und die für den jeweiligen Belegzweck relevanten Inhalte
geprüft. Die PDF-Vorschau wurde als eigene Hochformatklasse betrachtet. Es
wurden keine fehlenden Unfallmarker, unlesbaren Legenden oder gebrochenen
Zustände gefunden. Die Originalprüfung machte in der PDF-Vorschau zugleich
eine verwaiste Fortsetzungszeile („Wochentag).“) vor dem Antrag sichtbar. Der
PDF-Renderer hält den kurzen Methodikblock deshalb nun untrennbar zusammen;
die nächste Screenshot-Generation prüft und ersetzt diesen historischen
Beleg, bevor #404 abgeschlossen wird.

Die maschinelle Abschlussprüfung erfolgt mit:

```bash
npm run validate:media -- --report .build/qa/media-report.json
npm test -- --runInBand tests/unit/docMediaPolicy.test.js tests/unit/regen-readme-demo.test.js
```
